# Wage-Gap-Final-Project

Group members: Obydah Jazaeri, Alli Nemec, Samya El Boghdadi, Roya Hashimi

Data source: [US Bureau of Labor Statistics](https://www.bls.gov/cps/), Labor Force Statistics from the Current Population Survey, 2014-2024. 

## Project description

This project explores wage trends and wage inequality in the United States from 2014 to 2024 using data from the U.S. Bureau of Labor Statistics (BLS) Current Population Survey (CPS). 
By using interactive visualizations, we examine how factors such as gender, education, race, and employment relate to earnings and wage gaps over time.

Our goal is to identify important patterns and determine whether wage disparities have changed over the past decade. 
By highlighting key trends in the labor market, this project provides insight into issues of economic opportunity and pay equity.
